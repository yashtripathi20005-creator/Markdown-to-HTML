# Markdown to HTML Converter

A simple, pure Python converter that transforms Markdown into clean HTML. No external dependencies required.

## Features

- Headings (`#` to `######`)
- Bold (`**bold**` or `__bold__`)
- Italic (`*italic*` or `_italic_`)
- Inline code (`` `code` ``)
- Fenced code blocks (```` ``` ````)
- Unordered lists (`-`, `*`, `+`)
- Ordered lists (`1.`, `2.`)
- Links (`[text](url)`)
- Images (`![alt](url)`)
- Blockquotes (`> `)
- Horizontal rules (`---`, `***`, `___`)

## Usage

### Command Line

```bash
python converter.py input.md output.html
